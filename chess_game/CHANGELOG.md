### 기술적 결정사항

1. **보드 표현**
   - Marker 엔티티 사용 (각 칸)
   - 3x3 블록 크기로 칸 표현
   - 좌표: (file * 3, 0, rank * 3)

2. **기물 표현**
   - Armor Stand 사용 (Marker=1b, Invisible=1b)
   - NBT 데이터에 모든 정보 저장
   - CustomName으로 스택 정보 표시

3. **UI 방식**
   - tellraw 클릭 이벤트 사용
   - carrot_on_a_stick으로 클릭 감지 (chess.click)

4. **좌표 시스템**
   - 파일(file): 0-7 → a-h
   - 랭크(rank): 0-7 → 1-8
   - 월드 좌표: 중심 (0, 64, 0) 기준
