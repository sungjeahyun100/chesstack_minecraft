# 시각적 개선 사항 및 사용 가이드

## 🎨 시각적 기능

### 1. 3D 체스 보드
- **체크무늬 패턴**: 흰색/검은색 콘크리트로 칸 구분
- **테두리**: 각 칸을 그레이 콘크리트로 구분
- **좌표 표시**: a-h (파일), 1-8 (랭크) 라벨
- **황금 테두리**: 보드 주변에 금 블록 테두리
- **에메랄드 코너**: 4개의 코너에 에메랄드 블록

### 2. 기물 아이콘
각 기물은 item_display로 표현됩니다:

#### 백 기물 (흰색)
- **킹** 👑: 플레이어 머리 (MHF_King)
- **퀸** ⭐: 네더의 별
- **룩** 🏰: 모루 (작은 크기)
- **비숍** ⛪: 엔드 막대
- **나이트** 🐴: 말 머리 (MHF_Horse)
- **폰** ⚔️: 철 주괴 (작은 크기)

#### 흑 기물 (검은색)
- **킹** 👑: 위더 스켈레톤 해골
- **퀸** ⭐: 네더의 별 (발광)
- **룩** 🏰: 모루 (작은 크기)
- **비숍** ⛪: 엔드 막대
- **나이트** 🐴: 좀비 말 머리
- **폰** ⚔️: 석탄 (작은 크기)

#### 특수 효과
- **로얄 피스**: 발광 효과 (Glowing)
- **항상 밝게**: 모든 기물은 밝기 15로 표시

### 3. 이동 시각화

#### 선택된 칸
- 엔드 로드 파티클
- 발광 블록 (level 15)

#### 이동 가능한 칸 (valid_move)
- 초록색 파티클 (happy_villager)
- 컴포스터 파티클

#### 공격 가능한 칸 (attack_move)
- 빨간색 더스트 파티클
- 화난 주민 파티클

### 4. UI 디스플레이

#### 게임 타이틀
- 보드 중앙 위 (y=5): "체스택" (큰 금색 텍스트)

#### 턴 표시
- 보드 중앙 위 (y=4): 현재 턴 표시
  - "백 턴" (흰색) 또는 "흑 턴" (회색)

#### 포켓 점수
- **왼쪽** (x=-2): 백 플레이어 포켓 점수
- **오른쪽** (x=23): 흑 플레이어 포켓 점수
- 실시간 업데이트

## 📍 보드 위치
- **중심 좌표**: (0, 64, 0)
- **크기**: 24x24 블록 (3블록 × 8칸)
- **높이**: y=64를 기준으로 배치

## 🎮 시각적 피드백

### 기물 스택 정보
각 기물의 이름표에 표시:
```
♔ King [S:0 M:3]
```
- S: 스턴 스택 (빨간색)
- M: 이동 스택 (초록색)

### 실시간 업데이트
- 기물 아이콘: 20틱마다 갱신 (성능 최적화)
- 파티클: 매 틱 표시
- UI 텍스트: 매 틱 업데이트

## 🔧 최적화

### 성능 고려사항
1. **기물 아이콘**: 5틱마다만 재생성 (기존 삭제 후 재생성)
2. **파티클**: 소량만 생성 (과도한 파티클 방지)
3. **조건부 실행**: 필요할 때만 업데이트

### 엔티티 관리
- `kill @e[type=item_display,tag=piece_icon,distance=..0.5]`로 중복 방지
- 게임 시작 시 모든 디스플레이 엔티티 정리

## 💡 사용 팁

### 보드 보기
1. 게임 시작 후 보드 중심 (0, 64, 0)으로 이동
2. 위에서 내려다보거나 옆에서 보기 편함
3. F5로 3인칭 시점 추천

### 기물 구분
- 흰색 vs 검은색 아이콘으로 쉽게 구분
- 로얄 피스는 발광 효과로 즉시 확인 가능
- 스택 정보는 기물 위 이름표로 확인

### 이동 확인
- 이동 가능한 칸: 초록 파티클
- 공격 가능한 칸: 빨간 파티클
- 현재 선택: 엔드 로드 파티클

## 🎬 효과 제거


## 📝 추가 개선 가능 사항

1. **애니메이션**
   - 기물 이동 시 부드러운 이동 애니메이션
   - 캡처 시 사라지는 효과

2. **사운드**
   - 기물 이동 소리
   - 캡처 소리
   - 턴 전환 소리

3. **더 많은 시각 효과**
   - 체크 상태 경고
   - 승리 시 화려한 효과
   - 특수 행동 시 이펙트

4. **커스터마이징**
   - 보드 색상 변경
   - 기물 아이콘 변경
   - 테마 설정
