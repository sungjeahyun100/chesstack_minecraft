# 체스택 빠른 시작 가이드

## 1단계: 데이터팩 로드 확인
게임에 접속하면 다음과 같은 메시지가 표시됩니다:
```
체스택 데이터팩이 로드되었습니다!
'/function chess:start'로 게임을 시작하세요.
```

## 2단계: 게임 시작
```
/function chess:start
```

이 명령어는:
- 8x8 체스 보드를 생성합니다
- 백과 흑 플레이어를 설정합니다
- 각 플레이어의 초기 킹을 배치합니다 (백: e1, 흑: e8)
- 각 플레이어에게 39점의 포켓 점수를 부여합니다

## 3단계: 행동 메뉴 열기
```
/function chess:action/menu
```

또는 간단히:
```
/function chess:menu
```

## 4단계: 게임 플레이

### 턴 구조
각 턴마다 다음 중 **하나의 행동만** 선택할 수 있습니다:

1. **착수** - 포켓에서 기물을 보드에 배치
2. **이동** - 보드의 기물을 움직임
3. **계승** - 기물을 로얄 피스로 만들기
4. **위장** - 로얄 피스를 다른 기물로 위장
5. **스턴** - 기물에 스턴 스택 부여

### 착수하기
1. 행동 메뉴에서 `[착수]`를 클릭
2. 배치할 기물을 선택 (포켓 점수 확인 필요)
3. 배치할 칸을 우클릭

**주의사항:**
- 프로모션 가능 기물은 프로모션 칸에 착수 불가
- 포켓 점수가 부족하면 배치 불가

### 이동하기
1. 행동 메뉴에서 `[이동]`를 클릭
2. 이동할 기물을 우클릭
3. 이동할 칸을 클릭

**제약사항:**
- 스턴 스택이 1 이상이면 이동 불가
- 이동 스택이 0이면 이동 불가
- 한 턴에 한 기물만 이동 가능 (단, 이동 스택이 있으면 여러 번)

### 스택 시스템 이해하기

#### 스턴 스택 (빨간색 S)
- 기물 배치 시 기물 점수만큼 부여
- 1 이상이면 **기물 이동 불가**
- 매 턴 종료 시 1씩 감소
- 기물을 잡으면 잡힌 기물의 스턴 스택 계승

#### 이동 스택 (초록색 M)
- 한 턴에 이동할 수 있는 횟수
- 이동할 때마다 1 감소
- 턴 시작 시 갱신:
  - 1~2점 기물: 5
  - 3~5점 기물: 3
  - 6~7점 기물: 2
  - 8점 이상: 1
- 기물을 잡으면 잡힌 기물의 이동 스택 계승

### 턴 종료
```
/function chess:turn/end
```
또는 행동 메뉴에서 `[턴 종료]` 클릭

## 5단계: 승리하기
상대의 **로얄 피스**(킹)를 잡으면 승리합니다!

## 유용한 명령어

### 메뉴 열기
```
/function chess:menu
```

### 게임 리셋
```
/function chess:reset
```

### 행동 메뉴
```
/function chess:action/menu
```

## 기물 점수표

| 기물 | 점수 | 초기 이동 스택 |
|------|------|----------------|
| 폰 | 1 | 5 |
| 나이트 | 3 | 3 |
| 비숍 | 3 | 3 |
| 킹 | 4 | 3 |
| 룩 | 5 | 3 |
| 퀸 | 9 | 1 |

## 팁

1. **포켓 관리**: 39점을 효율적으로 사용하세요
2. **스턴 활용**: 강력한 기물은 스턴이 오래 걸립니다
3. **이동 스택**: 저점수 기물은 한 턴에 여러 번 이동 가능합니다
4. **로얄 피스 보호**: 킹을 잃으면 패배합니다
5. **스택 계승**: 기물을 잡으면 더 강력해집니다!

## 문제 해결

### 게임이 시작되지 않아요
```
/reload
/function chess:start
```

### 보드가 이상해요
```
/function chess:reset
/function chess:start
```

### 턴이 넘어가지 않아요
```
/function chess:turn/end
```
