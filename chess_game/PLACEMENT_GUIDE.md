# 기물 착수 시스템 사용 가이드

## 개요
기물 착수 시스템은 플레이어가 포켓에서 기물을 선택하여 보드에 배치할 수 있게 합니다.

## 사용 방법

### 1. 착수 시작
```
/function chess:action/menu
```
행동 메뉴에서 `[착수]`를 클릭하거나

```
/function chess:piece/place/menu
```
직접 기물 배치 메뉴를 엽니다.

### 2. 기물 선택
- **폰** - 1점
- **나이트** - 3점
- **비숍** - 3점
- **룩** - 5점
- **퀸** - 9점

원하는 기물을 클릭하여 선택합니다.

### 3. 칸 선택
1. **당근 낚싯대(Carrot on a Stick)를 손에 들기**
2. 배치하고 싶은 칸을 조준
3. **우클릭**하여 배치

배치 모드에 있을 때는 화면에 보라색 파티클이 표시됩니다.

### 4. 배치 취소
스니크(Shift 키)를 누르면 언제든지 배치를 취소할 수 있습니다.

## 배치 규칙

### 영역 제한
- **백 플레이어**: 1랭크(a1-h1) ~ 4랭크(a4-h4)에만 배치 가능
- **흑 플레이어**: 5랭크(a5-h5) ~ 8랭크(a8-h8)에만 배치 가능

### 포켓 점수
- 각 플레이어는 39점의 포켓 점수로 시작
- 기물을 배치할 때 해당 기물의 점수만큼 차감
- 포켓 점수가 부족하면 배치 불가

### 스턴 스택
기물을 배치하면 자동으로 스턴 스택이 부여됩니다:
- **폰**: 1 스턴 스택 (다음 턴부터 이동 가능)
- **나이트/비숍**: 3 스턴 스택
- **룩**: 5 스턴 스택
- **퀸**: 9 스턴 스택

스턴 스택은 매 턴 종료 시 1씩 감소하며, 0이 되면 이동할 수 있습니다.

## 에러 메시지

### "이미 기물이 있는 칸입니다!"
해당 칸에 이미 다른 기물이 있습니다. 빈 칸을 선택하세요.

### "백은 1-4랭크에만 배치할 수 있습니다!"
백 플레이어는 보드의 아래쪽 절반에만 배치할 수 있습니다.

### "흑은 5-8랭크에만 배치할 수 있습니다!"
흑 플레이어는 보드의 위쪽 절반에만 배치할 수 있습니다.

### "포켓 점수가 부족합니다!"
선택한 기물을 배치할 만큼의 포켓 점수가 없습니다. 더 저렴한 기물을 선택하세요.

## 기술적 세부사항

### 레이캐스트 시스템
- 플레이어의 시선 방향으로 레이캐스트 실행
- 0.3블록 간격으로 탐색
- 최대 15블록까지 탐색
- 3x3 영역에서 가장 가까운 칸 감지

### 태그 시스템
- `placing`: 배치 모드 활성화
- `placing_pawn`, `placing_knight`, 등: 선택한 기물 종류

### 스코어보드
- `chess.placing_cost`: 선택한 기물의 비용
- `chess.pocket`: 남은 포켓 점수
- `chess.sneak`: 스니크 감지 (배치 취소용)
